# Auto servis

Next.js projekat za sajt auto-mehaničarske radionice, na srpskom jeziku (latinica).

## Pokretanje

Instalirajte Node.js, pa pokrenite:

```bash
npm install
npm run dev
```

Aplikacija će biti dostupna na http://localhost:3000.

## Provera produkcione verzije

```bash
npm run lint
npm run build
```

Početna stranica je privremeni početni okvir; konačan izgled biće urađen prema dizajnu koji ćete poslati.
